# Ad Sample Images

This folder contains sample images for Box Ads and Classified Ads that will be shown in hover popups on the booking page.

## Required Images

### Box Ad Samples
Add 3 images for box ad samples with the following names:
- `box-ad-sample-1.jpg`
- `box-ad-sample-2.jpg`
- `box-ad-sample-3.jpg`

### Classified Ad Samples
Add 3 images for classified ad samples with the following names:
- `classified-ad-sample-1.jpg`
- `classified-ad-sample-2.jpg`
- `classified-ad-sample-3.jpg`

## Image Guidelines
- Format: JPG, PNG, or WebP
- Recommended size: 300x400 pixels (portrait) or 400x300 pixels (landscape)
- Keep file size under 200KB for faster loading
- Images should clearly show examples of the ad type

## How It Works
When users hover over the "Box Ad" or "Classified" buttons on the booking page, a popup will appear showing these sample images to help them understand what each ad type looks like.
