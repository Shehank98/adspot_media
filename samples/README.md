# 📋 AdSpot Media - Classifieds Section Samples

These are **sample/demo HTML files** - NOT connected to the live site or database.
Use these to visualize how the classifieds section will look before building it.

---

## 📁 Files Included:

### 1. **classifieds-listing-sample.html**
- **What**: Public listing page (like ikman.lk homepage)
- **Shows**: Grid of all classified ads with filters
- **Features**:
  - Search bar with category/location filters
  - Sidebar filters (price, location, category, condition)
  - Ad cards in grid layout
  - Featured ads highlighted
  - Sort options (newest, price, popular)
  - Responsive design

### 2. **classifieds-ad-sample.html**
- **What**: Single ad detail view
- **Shows**: Full ad details with image gallery
- **Features**:
  - Image gallery with thumbnails
  - Complete ad description
  - Vehicle/product details grid
  - Contact seller buttons (Call, WhatsApp)
  - **SHARE FEATURE**:
    - Convert ad to beautiful JPG image
    - Share on WhatsApp & Facebook
    - Copy link
    - AdSpot branding on shared image
  - Mobile responsive

### 3. **admin-classifieds-sample.html**
- **What**: Admin panel to manage all classifieds
- **Shows**: Dashboard view for admin
- **Features**:
  - Statistics (Total, Featured, Pending, Expiring)
  - Filter & search ads
  - Table view of all ads
  - Actions: View, Feature, Approve, Delete
  - Status badges (Active, Pending, Expired, Featured)
  - Pagination
  - Modals for confirmation

### **Option 1: Open Directly**
```bash
# Navigate to samples folder

# Open any file in browser
# Right-click file → Open with browser
```

### **Option 2: Local Server**
```bash
cd /home/user/adspot_media/samples/
python3 -m http.server 8000
# Visit: http://localhost:8000/classifieds-listing-sample.html
```

### **Option 3: Live Preview (VS Code)**
- Install "Live Server" extension
- Right-click any HTML file → "Open with Live Server"
